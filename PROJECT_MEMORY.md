## File Map
- `backend/main.py`: FastAPI server entry point and endpoint definitions.
- `backend/ingest.py`: Core logic for importing batches and generating summary metrics (deterministic math).
- `backend/ai/ollama_client.py`: Client for interacting with the local Gemma 3 4B model.
- `backend/ai/orchestrator.py`: AI controller that orchestrates tool calls and generates final chat responses.
- `backend/ai/tools.py`: Definition and execution logic for the tools exposed to the AI.
- `backend/ai/verifier.py`: Deterministic verifier that blocks the AI from hallucinating ungrounded numbers.
- `backend/analysis/forecast.py`: Generates the rolling-average cash position forecast deterministically.
- `backend/db/firestore_client.py`: Abstraction layer for interacting with Firebase/Firestore.
- `data/generate_data.py`: Script to generate synthetic test data (CSVs) for ingestion.
- `docs/`: Markdown documentation folder containing PRD, TRD, Schema, Video Script, etc.
- `eval/eval_matching.py`: Script to evaluate the deterministic matching engine's accuracy against ground truth.
- `eval/eval_qa.py`: Script to evaluate the AI's question answering and hallucination resistance.
- `frontend/src/App.tsx`: Main React application component and router.
- `frontend/src/context/AIContext.tsx`: React Context for global AI chat state and UI tool callbacks.
- `frontend/src/pages/`: React page components for Dashboard, Exceptions, CashPosition, Onboarding, and AskYourBooks.
- `matching/matcher.py`: Core deterministic reconciliation engine that pairs settlements with bank/ledger records.

## Known Constraints
- Matching, scoring, confidence calculation, and all arithmetic on money are done in deterministic Python code — never by the LLM.
- The AI (Gemma 3 4B) only explains, summarizes, answers questions, and triggers navigation — always grounded in tool-call results, always checked by the verifier before display.
- Every number shown in the UI must have a 'Why?' breakdown traceable to source records.

## Known Stubs / TODOs
- **Connectors**: UPIConnector and BankAAConnector in `main.py` are stubbed classes returning hardcoded unavailability (intentional scope constraint).
- **Data Generation**: All transaction records (CSVs) are entirely synthetic, generated by `data/generate_data.py`.
- **Chart Intents**: `AskYourBooks.tsx` uses hardcoded keywords to determine chart types instead of true semantic parsing.
- **Frontend Config**: API base URL `http://127.0.0.1:8000` is hardcoded across React components instead of using environment variables.
